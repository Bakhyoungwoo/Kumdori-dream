# OURCUT Mobile

좋아하는 사람과 한 컷에 담는 AI 네컷 합성 앱의 모바일 화면입니다.

![화면 미리보기](./assets/images/overview.png)

## 사용자 흐름

```text
첫 화면 ─┬─ 로그인 ──────────────┐
         └─ 회원가입 → 가입 완료 ─┴→ 홈
                                      │
          ┌───────────────────────────┘
          ▼
   프레임 선택 → 사진 입력 → 생성 설정 → 생성 진행 → 결과 상세
                                                        │
                                  갤러리 (다시 보기 · 삭제) ◀┘
```

## 회원

![회원 흐름](./assets/images/auth-flow.png)

첫 화면 → 회원가입 (입력 검증 · 중복 이메일 안내) → 가입 완료 → 로그인 (실패 안내)

## 사진 만들기

![사진 만들기 흐름](./assets/images/photo-flow.png)

프레임 목록 → 사진 입력 (2/4 → 4/4) → 생성 설정 (기본 합성 / 생성형 합성) → 생성 진행 → 완성

- **기본 합성**: 무료, 사진을 프레임에 자연스럽게 배치
- **생성형 합성**: 원하는 분위기를 글로 적고 1~4장 생성, 하루 10장까지

## 갤러리 · 결과

![갤러리와 결과 흐름](./assets/images/gallery-flow.png)

갤러리 → 선택 삭제 → 결과 상세 (여러 장 넘기기) → 다시 생성 확인 → 삭제 확인 → 기본 합성 결과
