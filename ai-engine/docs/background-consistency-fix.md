# 배경·인물 합성 일관성 수정 기록

## 수정 전 문제

인물의 얼굴과 꿈돌이는 정상적으로 생성되었지만, 인물과 배경이 서로 다른 사진을
붙인 것처럼 보였다. 인물의 조명, 색온도, 원근, 크기와 배경의 촬영 조건이 맞지
않았고 발밑 접지 그림자와 주변광도 부족했다.

## 적용한 코드 수정

### 최종 프롬프트 제약 강화

`FINAL_IMAGE_CONSTRAINTS`에 다음 조건을 추가했다.

- 동일한 카메라 시점과 렌즈 원근
- 인물과 배경의 크기·노출·화이트밸런스 일치
- 조명 방향·색온도·피사계 심도·필름 그레인 일치
- 자연스러운 경계와 가림(occlusion)
- 인물과 꿈돌이의 접지 그림자 및 주변광 생성
- 오려 붙인 듯한 합성 및 스튜디오 조명 불일치 금지

### 입력 이미지 역할 명시

OpenAI 이미지 생성 호출에서 입력 파일 이름과 프롬프트 역할을 명확히 했다.

- `identity-reference.png`: 사용자의 얼굴과 신원을 보존하는 기준
- `character-or-scene-reference.png`: 꿈돌이 또는 장면 참고 이미지

두 이미지를 하나의 일관된 사진으로 통합하도록 최종 프롬프트에 명시했다.

## 검증 결과

수정 후 실제 `generative_pipeline`과 OpenAI 이미지 생성 API를 다시 호출했다.

- `generation_mode`: `OPENAI_IMAGE`
- `current_step`: `COMPLETED`
- 결과: `results/live-image-background-fix/result-1.png`
- 자동 테스트: `21 passed`

수정 후 결과에서는 인물과 꿈돌이의 크기·원근·조명·접지감이 이전보다 자연스럽게
맞았지만, 생성 모델 특성상 완전한 사진 합성을 보장하지는 않는다. 더 높은 품질이
필요하면 야외 전신 참조 사진, 인물 마스크, 광원 추정, 색상 보정과 실제 그림자
합성 단계를 추가로 적용한다.
