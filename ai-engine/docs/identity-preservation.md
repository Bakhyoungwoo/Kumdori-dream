# 인물 정체성 보존 및 파인튜닝 판단 기록

## 테스트 관찰

증명사진과 꿈돌이를 함께 사용한 테스트에서 꿈돌이는 정상적으로 생성되었지만,
사용자 얼굴은 다른 사람처럼 생성되었다.

## 판단

이 결과 한 번만으로 파인튜닝이 필요하다고 판단하지 않는다. 증명사진 한 장은
각도·표정·조명 변화에 대한 정보가 부족하고, 이미지 생성 모델이 장면과 스타일을
우선하다가 얼굴 특징을 일반화할 수 있다.

먼저 다음 순서로 개선한다.

1. 정면·고해상도·얼굴이 크게 보이는 사진을 사용한다.
2. 가능하면 표정과 각도가 조금 다른 사용자 사진을 3~10장 사용한다.
3. 프롬프트에서 첫 번째 사용자 사진을 얼굴/신원 기준으로 명시한다.
4. 꿈돌이 또는 프레임 이미지는 장면·구도 기준이며 사람의 신원을 대체하지 않는다고 명시한다.
5. 이미지 입력의 참조 강도를 높이고, 여러 결과에서 얼굴이 일관되는지 확인한다.

이 과정을 거친 뒤에도 반복적으로 다른 사람이 나오면 얼굴 전용 LoRA 또는 개인화
학습을 검토한다. 파인튜닝은 데이터 준비와 과적합 위험이 있으므로 기본 해결책으로
사용하지 않는다.

## 현재 코드의 적용 기준

- 첫 번째 subject 이미지를 사용자 신원 기준으로 취급한다.
- 추가 subject 이미지는 같은 사람의 보조 참조 이미지로 취급한다.
- frame 이미지는 장면과 레이아웃 참조로만 취급한다.
- OpenAI 이미지 생성 호출은 높은 입력 충실도(`input_fidelity="high"`)를 사용한다.
- 최종 프롬프트에는 얼굴·신원·나이·체형을 유지하고 다른 사람으로 바꾸지 말라는
  제약을 포함한다.

## 재평가 기준

사진 품질과 참조 설정을 개선한 뒤 최소 3회 이상 생성해도 얼굴 유사도가 낮으면
개인화 학습을 검토한다. 한 번의 실패만으로 모델 학습을 시작하지 않는다.
